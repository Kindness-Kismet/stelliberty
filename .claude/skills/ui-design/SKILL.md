## 执行流程

1. 阅读项目 AGENTS，按实际控件类型选择指南，再阅读所用框架的代码示例。
2. 核对已有组件库，优先复用其内置样式和交互；按已明确的控件要求调整必要差异，库未覆盖的动画由公共封装补齐。
3. 接入前核对组件已有动画，复用或替换对应效果，使每个交互采用1套反馈。组件、样式和动画尽可能复用，同类型控件使用公共组件及样式变体。
4. 尺寸使用 100% 逻辑单位，颜色、圆角和动画集中到主题参数；保留键盘、焦点、禁用和取消交互。
5. 按项目真实框架和版本接入示例，复用现有状态与生命周期，保持动画执行期间 UI 主线程及时响应输入与渲染。

## 控件与视觉

- 界面文案围绕当前操作提供所需信息，合并重复说明，每条提示对应实际状态。
- 按钮按语义分型：透明变体的悬停底色设为 `transparent`，中性关闭按钮与强调色业务按钮保留悬停反馈；按压使用微缩放。
- 强调色上的文字按实际背景对比度选择深色或浅色。
- 所有按钮默认将阴影设为空；悬浮容器使用统一默认投影，具体参数见阴影指南。
- 复合列表项按压时轻微加深背景与装饰图标，标题、副标题保持原色；圆角按最近圆角表面容器派生。
- 文字标签有悬停与按压底色，图标标签保持透明；切换使用渐入渐出。
- 持久选中样式由业务选中状态决定；选中项的底色按选中态渲染，覆盖 hover 底色。
- 菜单外点击先由菜单消费当次输入，再关闭菜单。

## 完成与维护

1. 使用项目 `app-debug` 验证本次交互与过渡，检查按下、释放、移出取消及最终状态，并核对相关控件参数、选中与悬停优先级和菜单输入消费结果。
2. 可复用参数、动画公式或代码变化时，同步更新对应指南，核对指南与实际实现一致。
