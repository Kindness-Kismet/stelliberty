# 隐私性审查

先阅读根目录 `AGENTS.md`，从实际 Git 状态确定当前本地分支与远端。审查范围为 `<remote>/main..<当前本地分支>` 的全部提交，检查文件内容、提交说明与归档中携带的本机独特路径。

使用本技能的 `scripts/run.py`；入口从自身目录定位项目，Codex 主源与 Claude 镜像采用相同实现。

## 执行流程

1. 核对当前分支、远端和工作区状态。远端默认采用 `origin`，项目使用其他远端时按实际名称传入 `--remote`。
2. 执行扫描入口，更新选定远端的 `main` 引用，固定本次比较的 base 与 head 提交 SHA。
3. 阅读范围内全部新增可达提交的扫描结果，包括并入分支的提交、后续已删除的文件内容和提交说明。
4. 按提交号、仓库相对路径、行号与归档成员定位候选，阅读相应 Git 对象中的上下文，区分本机独特路径、通用安装路径、动态变量和明确标注的示例。
5. 对报告中的覆盖待核对项按实际文件格式补充检查；确认每项候选与覆盖结果后，给出该提交范围的路径审查结论。

## 调用方式

```text
python .codex/skills/privacy-review/scripts/run.py --check
python .codex/skills/privacy-review/scripts/run.py --check --remote <remote>
python .codex/skills/privacy-review/scripts/run.py --check --json
python .codex/skills/privacy-review/scripts/run.py --check --output build/privacy-review/report.json
```

- `--repo <path>` 指定其他待检查项目；范围仍由该项目当前本地分支与选定远端的 `main` 决定。
- 无参数与 `--help` 展示相同英文帮助，退出码为 `0`；实际扫描使用 `--check`。
- 普通输出采用统一标题、2个空格缩进与2位小数耗时；`--json` 在 stdout 返回完整 JSON，过程与诊断写入 stderr。
- `--output` 将同一份脱敏报告保存为 UTF-8 JSON；默认结果直接显示在终端。

## 路径核对

- 本机独特路径包括带个人用户目录、私人工作区、临时目录或设备网络共享的绝对路径，覆盖 Windows、Unix 与 Git Bash 等实际写法。
- 脚本读取 Git 提交对象，覆盖目标范围内的历史文件版本；候选匹配作为人工核对的定位依据。
- 通用安装目录、仓库相对路径、环境变量和示例按实际语义分类，结论以是否绑定具体本机环境为准。
- 文本、ZIP 成员与可识别编码由脚本处理；加密内容、超出读取限额的对象、需要额外解读的二进制和子模块变动列为覆盖待核对项。
- 报告保留提交号、仓库相对位置、行号与问题类别。命中的私人路径原文在本地阅读，公开说明使用脱敏位置。
- 修复建议采用仓库相对路径、运行时定位或明确配置来源；实际修改文件与提交历史按本次用户授权及对应 skill 执行。

## 完成与维护

退出码 `0` 表示扫描完成且候选为空，`1` 表示存在需要核对的路径候选，`2` 表示执行失败或有覆盖待核对项。前提或覆盖待补齐时，说明具体位置与所需操作，补齐后再给出完整结论。

完成后简要说明实际分支、`<remote>/main`、比较 SHA、提交数量和核对结果。发现本机独特路径时，附提交号、脱敏后的文件位置与修正方向。

可复用扫描、路径识别和输出模块全部保存在本技能 `scripts/` 中，随技能整体安装和同步。
