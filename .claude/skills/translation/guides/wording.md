# 字符串写法

- 按钮和菜单用动词开头。中文进度标签用“动作 + 中”，例如“删除中”“保存中”“同步中”。任务开始、结束和失败分别由对应状态触发。
- 中文结果优先用“对象 + 已 + 动作”。同一行已经标明对象时可简写为“已删除”。英文按钮用动词原形和句首大写，结果可用短语 `File deleted`。执行者影响理解时才点明，例如“管理员已关闭共享”。
- 标签用短语，提示通常一句说清。同一句优先写用户能做什么，例如“先选择文件，再继续”。失败、缺失或禁止操作时，直接说明事实，例如“没有权限删除此文件”。涉及永久删除等后果，保留用户决定前需要知道的信息。
- 专业英文缩写、协议名、API 名和产品术语按行业写法保留。中文与相邻的英文单词、缩写之间留一个半角空格，例如“检查 API 权限”“导出 JSON 文件”。
- 中文数量短语中，阿拉伯数字与量词之间留一个半角空格，量词与名词连写，例如“已选择 2 个文件”。数量占位符按渲染后的文字留空格，如“共 {count} 条记录”。代码、版本号和资源键保留原格式。
- 展示层按错误类型、错误码或当前操作选择翻译键，以当前界面语言呈现失败原因。例如删除操作返回 `PermissionDenied` 时显示对应的权限提示。原因未知时说明哪项操作失败，恢复方法确实可用时再补充。
- 变量随整句进入资源，允许译者调整词序。保留参数的含义、数量和类型，按目标语言处理单复数。核对 1 和 2 等能触发不同词形的值。
- 同一概念和用途采用同一译法。按钮、状态标签和独立提示各按实际语境选词，常用表达见[中英文词典](glossary.md)。
