# Qt 文案标识与资源

| 模式 | “保存更改”的调用 | 查找与维护 |
|---|---|---|
| 源文案 | C++ 用 `tr("Save changes")`，QML 用 `qsTr("Save changes")` | 上下文、源文案和可选消歧文本共同标识消息。修改原文或移动上下文后，重新提取并复核译文。 |
| 稳定 ID | C++ 用 `qtTrId("settings.save_changes")`，QML 用 `qsTrId("settings.save_changes")` | 沿用项目 ID 约定，源文案用提取器支持的注释登记，并为默认语言提供能解析该 ID 的译文。 |

- Qt Linguist 的 `.ts` 是 XML 翻译源文件。按项目入口用 `lupdate` 更新消息，用 `lrelease` 生成运行时使用的 `.qm`。
- 在源文案模式中，若英文就是源语言，普通英文文本可直接显示原文。英语数量变化等需要译文的消息按项目配置生成源语言资源。
- 参数使用 `%1`、`%2` 等位置标记。数量消息使用 `%n` 并向翻译调用传入数量，由各语言的数量形式决定整句译法。
