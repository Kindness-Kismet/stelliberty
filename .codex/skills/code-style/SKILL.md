# 代码风格

先核对项目 AGENTS、实际语言版本、相邻代码及已生效的 formatter/lint，再查对应语言指南。项目已有的公共 API、外部契约和明确生效的配置优先；差异涉及既有接口或仓库约定时先确定修改范围。

## 执行流程

1. 按实际语言及改动职责阅读指南，核对相邻模块、语言版本和有效配置。多语言项目分别检查接口两侧。
2. 先理清输入、状态持有方、依赖和失败边界，再确定名称、导入、类型、可见性及控制流。只公开实际需要的接口。
3. 导入与模块调整追踪真实消费者；重命名核对外部导出、序列化、反射、FFI、命令行和动态加载契约，外部拼写按已有协议保留。
4. 按改动范围运行已有 formatter、类型检查、lint、构建或测试。新增工具或改变语言版本根据项目需求决定，不因整理风格引入运行时、框架或整套依赖。

## 控制流与资源

- 在真实输入、文件、网络、平台和 FFI 边界校验；内部已成立的不变量通过类型和调用契约表达。
- 函数入口优先用卫语句处理真实失败、空值或无操作前提，主流程保持扁平；不为提前返回编造防御分支。
- 逻辑嵌套最多 3 层，不计类型与函数；超过时按职责拆分。if/else 链超过 3 个分支时改为模式匹配、switch 或明确状态分发，对称二选一可直接保留。
- 错误携带上下文传播到能处理的边界；不逐层捕获后返回默认值，不为未经证明的情况添加 fallback。
- 资源和任务归属明确的所有者或作用域；及时释放，取消沿实际调用链传播，共享可变状态采用项目已有的同步机制。
- 废弃、重复和无消费者的代码按实际影响清理；删除、接口迁移和历史改写遵守任务授权。

## 错误与诊断

- 程序自有错误返回、异常、参数校验诊断、日志与协议错误消息使用英文，路径、代码和实际标识保留原样。
- OS 错误边界使用固定英文操作说明，并保留异常类型、errno/winerror 或原始错误码、filename/filename2 等实际字段；不直接拼接可能本地化的 `str(error)` 或系统错误描述。
- 错误传播保留英文上下文。第三方工具的原始 stderr 保留，工具支持时选择英文诊断。
- 应用需要显示失败提示时，由展示层按 [translation 的字符串写法](../translation/guides/wording.md) 处理。

## 注释

- 代码注释与开发规范使用简体中文，中英文之间空 1 格。
- 注释只说明意图、约束和边界，同段最多 2 行。
- 隐藏约束、平台差异、FFI 安全前提、魔法数字与易踩坑写法必须配一行精炼中文注释。
- 使用语言原生注释语法，例如 Rust/C#/C++/Kotlin/TypeScript 的 `//`、Python/Shell/YAML 的 `#` 和 XML/XAML 的 `<!-- -->`。

## 代码文件上限

- 单个自有代码文件最多 **2400 行，含注释与空行**，适用于主应用、桥接、共享脚本和 UI 声明代码，语言不影响上限。
- 超限按职责拆分，保持模块入口与依赖方向；不通过压缩空行、拼接长行或按编号分片规避。
- 检查实际纳入项目维护的代码输入，不因未跟踪或被忽略而漏掉；区分第三方依赖、工具产物与自有代码。
- 工程检查与提交前验证核对行数；存量超限列出拆分目标，未解决时保留不符合项。

## 按含义命名

| 要命名的内容 | 选词依据 | 示例 |
|---|---|---|
| 集合、数量、位置 | 集合用复数或集合名，数量、从零开始的索引和对外编号分别表达 | `entries`、`entryCount`、`entryIndex`、`pageNumber` |
| 状态、能力、历史结果 | 用一句可以回答“是 / 否”的话，分清当前是否打开、是否允许打开、是否已找到 | `isOpen`、`canOpen`、`found` |
| 读取、查找、解析 | 根据调用者获得的结果命名，复用该语言对缺项、失败和转换的表达 | `readEntry`、`findEntry`、`parseHeader` |
| 时间、大小 | 单位影响使用时写进名称，或使用带单位的类型 | `timeout`、`timeoutMs`、`sizeBytes` |
| 缩写 | 保留术语，采用对应语言的大小写 | Go 的 `HTTPClient`，Rust 或 C# 的 `HttpClient` |

表中拼写用于说明词义，代码采用对应语言的形式。作用域越广，名称越要能单独理解；结合包名、类型名和调用处清理重复词。布尔值用谓词，函数表达动作或返回值，变量表达所存内容。

## 完成与维护

核对真实调用方、外部契约和本次验证结果。项目特有的代码风格与命名例外写入对应语言指南，formatter/lint 配置继续作为实际执行入口。
