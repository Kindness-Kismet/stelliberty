# 标签切换

文字型标签有悬停和按压底色；图标型标签保持透明。两者不使用 ripple，保留选中指示、键盘焦点和真实切换动作。默认采用 `160 ms`、`linear` 的纯交叉渐变，不横移内容。

| 类型 | 悬停底色 | 按压底色 | 背景形状 |
|---|---|---|---|
| 未选中的文字型，含图标加文字 | `tab.textHoverBackground`，默认与导航列表同色，主题键独立 | 底色亮度 `0.92`、对比度 `1.12`；装饰图标局部反馈，文字不滤色 | 四侧内缩 `4`，圆角 `7` |
| 已选中的文字型 | 不叠加悬停底色，保留选中文字与指示线 | 保留文字型按压反馈 | 同上 |
| 纯图标型 | 透明 | 透明 | 保持原内容与选中指示 |

文字型底色随指针状态立即更新。未选中项悬停显示自己的主题底色，按下时轻微加深，释放后按实际指针位置与选中状态恢复。混合标签的装饰图标按下 `30 ms`、恢复 `72 ms`，沿用列表局部反馈；文字与指示线不套滤镜。已选中项不增加悬停背景块。移出后取消按压视觉，按住移回恢复；外层命中区域固定，背景内缩不缩小点击范围。`160 ms linear` 用于选中权重与内容切换。

## 状态与渐变

标签身份稳定，选中目标由业务或导航状态持有，动画只维护各标签和场景的显示权重。是否抑制悬停按业务选中目标判断，不使用 `weight > 0`，避免过渡中的新旧标签同时被视为选中。点击当前标签不重新启动切换；快速切换从当前实际权重接续。

```text
p = clamp(elapsed / effectiveDuration, 0, 1)
weight[i] = fromWeight[i] * (1 - p) + (i == target ? p : 0)
effectiveDuration = 160ms / speed
```

开始新切换前保存当前 `fromWeight`，取消旧动画及其完成回调。新、旧内容按同一进度交叉渐变；完成后只保留目标场景。渲染层保持背景稳定，文字、图标和指示线按同一权重变化。

旧场景退出后不继续接受输入，新目标经实际导航入口激活。保存各标签应保留的表单和滚动状态，显示变化不绕过数据加载、取消与生命周期。

## 指示与交互

选中指示线引用当前 `windowActiveTextFg` 或项目对应 accent 语义键，厚度 `2`、端点半径 `1`。普通标签前景引用当前文本语义色。先对选中的 accent 端点核对 `4.5:1`，不足时取背景的高对比黑/白，再从普通前景向该端点渐变，每帧核对最终文字；避免途中触发回退而闪变。指示线的不透明基色低于 `3:1` 时同样替换，再按选中权重设置显示 alpha。指示线渐入、渐出过程中允许对比度随透明度降低。参数统一从 [主题参数](tokens.md) 获取。

文字型背景按选中与指针状态绘制，图标型不通过通用按钮或列表组件加回底色。焦点指示与选中指示分开维护，键盘用户仍能辨认当前操作目标。

- 左键在标签内按下，释放仍在同一标签时切换；移出释放取消。
- 若标签栏支持拖动滚动，进入拖动后取消点击，释放不激活标签。
- 键盘方向键、Home、End 按实际控件语义选择标签；Space、Enter 的确认行为与项目导航约定一致。
- 禁用标签不激活；隐藏、销毁或更换目标时结束对应动画与旧完成回调。
- 调整窗口或主题后更新实际场景与颜色，不能继续使用尺寸或 palette 已失效的缓存。

## 框架接入与验证

采用 [Kotlin / Compose](frameworks/kotlin.md)、[Qt Widgets](frameworks/qt.md)、[GPUI](frameworks/gpui.md) 或 [Avalonia](frameworks/avalonia.md) 的共享标签状态和动画机制。项目版本与实际 API 核对后再接入，不按标签数量复制多份动画实现。

使用项目 app-debug 在 `1x` 与较慢倍率下检查切换中间帧：旧内容逐渐消失，新内容逐渐出现，标签指示同步改变。连续切换3次核对最终目标和当前权重接续，重复点击当前标签核对无额外切换；同时检查键盘、禁用、拖动取消与移出释放。

普通和选中标签在浅色、深色及用户强调色下保持可辨。未选中文字型核对悬停、按压及移出取消底色，选中项核对悬停不增加背景；图标型核对背景保持透明。导航与标签默认同色，单独覆盖一方主题键不影响另一方。两者均无 ripple。结束观察后恢复原动画倍率。
